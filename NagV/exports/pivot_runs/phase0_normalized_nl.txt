Every requestor's region must be exactly one of the following: 'NA', 'EU', or 'APAC'.

If the requested resource type is 'DATABASE', then the requestor must provide a valid business justification.

Every requested storage volume must be strictly less than 500 gigabytes.

For every request, the total request cost must be less than or equal to 1000 dollars.

Every requested memory allocation must not exceed the available memory quota of the requestor's team.

If the target environment of a request is 'PRODUCTION', then the MFA status of the requestor of that request must be true.

If the role of a requestor is 'ML_ENGINEER', then the 500-gigabyte storage limit is bypassed for that requestor.

If a request originates from an unverified IP address, then that entire request is denied.
