The requestor's region must be one of the following: "NA", "EU", or "APAC".

If the requested resource type is "DATABASE", a valid business justification must be provided.

The requested storage volume must be strictly less than 500 gigabytes.

The requested instance count multiplied by the instance unit cost must be less than or equal to 1000 dollars.

The requested memory allocation must not exceed the team's available memory quota.

If the target environment is "PRODUCTION", the requestor's MFA status must be true.

If the requestor's role is "ML_ENGINEER", the 500-gigabyte storage limit is bypassed.

If the request originates from an unverified IP address, the entire request is immediately denied.
